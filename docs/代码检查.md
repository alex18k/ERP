## 四、重点检查清单
### 1. 业务逻辑与流程
- 采购申请 → 审批 → 采购订单 → 收货 → 入库 → 发票校验 → 付款/财务过账是否闭环。
- 状态机是否合法：Draft、Submitted、Approved、Rejected、Ordered、Partially Received、Received、Invoiced、Closed、Cancelled；是否存在非法跳转。
- 审批阈值、审批层级、代理人、驳回、撤回、转审是否正确。
- 三单匹配：采购订单、收货单、发票的数量、金额、税率、币种是否一致。
- 是否允许超收、超开票、负数量、负金额、重复收货、重复开票。
- 退货、换货、折扣、运费、关税、汇率、税额计算是否正确。
- 供应商冻结、黑名单、资质过期是否拦截。

### 2. 数据一致性与并发
- 金额是否使用 decimal/BigDecimal，避免浮点误差；币种、汇率、精度是否正确。
- 事务边界是否覆盖订单、库存、财务凭证、审批记录。
- 并发审批、并发收货、并发开票是否加锁或乐观锁。
- 重复提交是否幂等；订单号、收货单号、发票号生成是否并发安全。
- 库存扣减、财务过账失败时是否有回滚或补偿。

### 3. 权限与安全
- 水平越权：采购员是否能看/改其他部门、其他供应商的订单。
- 垂直越权：普通采购员是否能审批、改价、关闭订单、过账。
- 职责分离：创建人不能自审批；审批人不能随意改金额。
- SQL 注入、XSS、CSRF、SSRF、文件上传、反序列化风险。
- 日志、异常、接口返回是否泄露敏感信息。

### 4. 接口与集成
- REST/API 参数校验、错误码、分页、排序、过滤是否安全。
- 与库存、财务、供应商门户、消息队列、ERP 主数据集成是否有超时、重试、幂等、补偿。
- 外部失败是否导致本地事务悬挂或数据不一致。

### 5. 性能与数据库
- N+1 查询、全表扫描、缺失索引、大事务、无分页查询。
- 采购订单、明细、收货、发票、审批历史、供应商表是否有外键、唯一约束、检查约束、审计字段。
- 高频查询字段是否有合适索引；金额、数量、状态字段类型是否合理。

### 6. 代码质量与可观测性
- 分层是否清晰，是否存在重复代码、硬编码、魔法值、配置泄露。
- 异常处理是否吞异常、错误码是否统一。
- 审计日志是否记录谁、何时、改了什么、旧值/新值。
- 关键链路是否有日志、指标、追踪。

### 7. 测试
- 单元、集成、端到端测试覆盖采购核心流程。
- 是否覆盖边界：零金额、最大数量、部分收货、超收、重复提交、并发、越权、外部失败。
- 测试是否依赖真实生产数据或外部不稳定服务。
