# ERP生产管理系统 - 项目概要说明

---

## 一、系统核心价值

本系统以**MRP（物料需求计划）**为引擎，打通从销售订单到生产发货的全流程。简单来说，帮您解决以下核心问题：

- 订单来了，需要多少物料？什么时候要采购/生产？
- 生产到哪一步了？哪个车间在忙？进度是否正常？
- 缺什么料？什么时候能到？会影响哪些订单？
- 生产能不能按时交货？产能够不够用？
- 库存还剩多少？哪些材料快用完了？

---

## 二、核心功能模块

### 2.1 基础数据管理

基础数据是一切管理的根基，先把"家底"理清楚，系统才能跑起来。

| 功能 | 说明 |
|------|------|
| 物料主文件 | 管理所有原材料、半成品、成品的基础信息（编码、规格、单位、分类、供应商等） |
| BOM管理 | 产品需要哪些零件、配件，按层级关系管理（即产品结构树） |
| 工艺路线 | 每个产品怎么生产，经过哪些工序、每道工序需要多少时间、用什么设备 |

### 2.2 订单管理

从客户下单到发货，全流程可视可追踪。

- **销售订单录入与审核** - 客户下单后快速录入系统
- **订单全流程跟踪** - 从下单→排产→生产→完工→发货，每个节点状态实时更新
- **逾期自动提醒** - 超过交期未完成的订单自动标红预警

### 2.3 MRP物料需求计算（系统核心引擎）

这是整套系统的"大脑"，自动帮您算清楚需要什么、缺什么。

- 根据销售订单，自动计算每种物料需要多少
- 扣除现有库存、在途采购量，算出真正的缺口
- 考虑安全库存（最低库存警戒线），防止断料
- 自动生成缺料清单和采购建议
- 支持批量运算，多个订单一起算，结果更准确

### 2.4 缺料检查与预警

缺料是生产最大的"敌人"，系统帮您提前发现、提前处理。

- **缺料物料排行榜** - 哪些物料缺得最多，一目了然
- **影响订单分析** - 缺这个料会影响哪些订单交期
- **在途到货跟踪** - 采购了的料什么时候到
- **催料状态监控** - 哪些物料需要催供应商

### 2.5 生产过程管理（加工单与车间执行）

把MRP的计算结果转化为车间的实际操作。

- **加工单自动生成** - MRP运算后自动创建生产任务
- **车间任务分配** - 把任务分配到具体车间、工位、人员
- **实时报工** - 工人做完一道工序，马上在系统里报工（做了多少、用了多少料）
- **生产进度追踪** - 实时掌握每个加工单的完成进度

### 2.6 采购管理

MRP算出需要买什么，采购模块负责把料买回来。

- **采购订单创建与审批** - 根据缺料清单生成采购建议，审批后转为正式采购单
- **供应商管理** - 管理供应商基本信息、历史合作记录
- **到货跟踪** - 采购的物料到哪了，是否按时到货

### 2.7 可视化看板

把数据变成直观的图表，让管理者一眼看清全局。

| 看板类型 | 显示内容 | 使用场景 |
|----------|----------|----------|
| 管理驾驶舱 | 订单完工率、产值、产能负荷、缺料订单数、准时交付率、良率 | 老板/厂长总览全局 |
| 订单追踪看板 | 每张订单全流程节点状态条，逾期红灯提示 | 销售/跟单人员追踪订单 |
| 车间电子看板 | 各工位当前任务、排产甘特图、实时报工、齐套状态 | 车间主任管理生产 |
| 缺料预警看板 | 缺料TOP榜、影响订单、在途到货、催料状态 | 采购/物控人员关注 |
| 库存看板 | 板材库存（按厚度/材质）、安全库存告警 | 仓库管理人员盘点 |

### 2.8 用户与权限管理

不同岗位看到不同数据，保证数据安全。

- **用户、角色管理** - 按岗位设置不同权限
- **数据隔离** - 车间只能看自己的数据，仓库只能看自己的库存
- **操作日志** - 谁在什么时间做了什么操作，全程记录

## 六、后续可扩展功能

系统上线后，可根据实际需要逐步扩展以下功能：

- **供应商绩效管理** - 跟踪供应商交货及时率和质量评分
- **生产能力分析** - 自动识别生产瓶颈，优化排产
- **质量管理模块** - 不良品统计、质检流程、质量追溯
- **移动端支持** - 手机/平板报工、审批，随时随地办公
- **报表导出** - 支持Excel、PDF等格式导出分析
- **API接口开放** - 与财务系统、仓储系统等第三方系统对接
