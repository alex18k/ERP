ERP 应用界面专业化与紧凑化改造 AGENT 指令
本文档可直接交给 AGENT 执行。
要求：直接修改代码，不要只给建议。
核心目标：在不改变业务逻辑的前提下，将现有 ERP 应用改造为高信息密度、紧凑、克制、统一的专业 ERP 风格。

1. 角色
你是资深 ERP 前端架构师 + UI/UX 工程师。

你需要：

理解现有 ERP 业务页面结构

复用项目已有组件库、设计系统、主题变量

直接修改前端代码与样式

保证功能不回归、交互不缺失、可访问性达标

输出可验证、可回滚、可评审的改造结果

2. 目标
在不改变业务逻辑、API、字段、路由、权限、数据结构的前提下，将现有 ERP 应用改造为：

高信息密度、紧凑、专业、克制

重点优化：报表页、维护页、列表页、详情页、表格、表单、筛选区、按钮、标题、弹窗、导航

桌面优先：1366×768 可高效使用，1280+ 最佳，最小适配 1024

视觉风格：专业 ERP 配色，细边框、浅灰底、白色内容面、深蓝主色、状态色克制

交互风格：少跳转、少弹窗、多抽屉、多内联编辑、操作路径短

3. 硬约束
不改业务逻辑、接口、字段、路由、权限、数据结构。

优先复用项目现有组件库、设计系统、CSS 变量、主题方案。

若项目已有设计规范，以现有规范为准；若无，按本文默认 Token 执行。

禁止：大圆角、渐变、重阴影、花哨动画、过大留白、过多装饰色。

保持可访问性：键盘可操作、焦点可见、对比度达标、必要 aria 标签。

所有样式必须走 design tokens / CSS 变量，禁止散落魔法值。

不引入非必要新依赖；如必须引入，先说明理由与影响。

保持国际化、主题切换、权限控制等现有能力。

4. 设计原则
信息优先：首屏尽可能展示更多有效数据，减少无效留白。

层级清晰：页面标题、区块标题、卡片标题、正文、辅助文字层级明确。

操作克制：每屏最多一个主按钮，危险操作必须弱化或二次确认。

一致统一：按钮、表格、表单、筛选区、弹窗、通知风格统一。

紧凑但不拥挤：控件高度、行高、间距统一，避免视觉疲劳。

专业 ERP 感：像成熟企业系统，而不是普通后台模板。

6.2 顶栏
高度固定 48px。

左侧放系统名或 Logo。

中间或左侧放面包屑。

右侧放全局搜索、通知、用户菜单。

背景白色，底部 1px 边框。

不要使用大阴影。

6.3 侧栏
宽度 220px，可折叠至 48px。

菜单项高度 32–36px。

图标 16px。

选中态：主色浅底 + 左侧 2px 主色条。

悬停态：浅灰底。

分组标题 12px，次文本色。

6.4 内容区
页面背景 --erp-bg。

内容卡片白色表面，1px 边框，圆角 3px。

模块间距 8–12px。

页面 padding 12–16px。

页面标题区与筛选区之间 8–12px。

6.5 面包屑
字号 12px。

次文本色。

当前页用主文本色。

分隔符使用 / 或 >，保持一致。

7. 报表页优化
7.1 筛选区
默认一行展示。

常用条件放前面：日期、组织、状态、关键字。

更多条件折叠。

查询、重置、导出、打印右对齐。

控件高度统一 28/32px。

标签与控件间距 4–8px。

7.2 KPI 摘要
使用小卡片，不要大图表占满首屏。

数值 20–24px / 600。

标签 12px。

卡片间距 8–12px。

最多展示 4–6 个关键指标。

7.3 图表
去装饰，浅色网格。

图例紧凑。

颜色不超过 5 种。

坐标轴文字 12px。

避免 3D、渐变、阴影。

7.4 表格
表头吸顶。

斑马纹。

悬停高亮。

选中态。

列多时固定左侧关键列 + 右侧操作列。

支持横向滚动。

支持排序、筛选、列宽调整。

支持合计行、分页、导出。

数字右对齐，金额千分位。

日期 YYYY-MM-DD。

空值显示 -。

状态用「文字 + 浅色标签」，不要只用颜色区分。

7.5 分页
靠右或靠下。

显示总数、每页条数、页码、跳转。

高度紧凑，不要占用过多首屏空间。

8. 维护页优化
8.1 列表 + 详情
列表操作列固定右侧。

编辑优先用抽屉或弹窗。

抽屉宽度 480–720px。

弹窗宽度根据字段数决定，最大不超过 720px。

主从表：上方主表，下方明细。

明细支持增删行、批量操作。

8.2 表单
分组展示。

2–3 列紧凑布局。

标签顶部或右对齐，保持一致。

必填加 *。

字段下方即时错误提示。

保存前统一校验。

只读字段使用浅灰背景。

审计字段只读。

8.3 底部操作
保存、取消固定底部。

主按钮每屏最多 1 个。

删除必须二次确认。

保存成功用轻提示，不要打断操作。

9. 按钮规范
9.1 按钮类型
类型	用途	样式
主按钮	保存、查询、提交	主色背景，白色文字
次按钮	取消、重置、返回	白底 + 边框
危险按钮	删除、禁用	红色背景或红色文字
文字按钮	查看、编辑、更多	无边框，主色文字
图标按钮	工具操作	必须有 tooltip
9.2 按钮尺寸
高度：28 / 32px。

圆角：3px。

图标：14 / 16px。

文字：12–13px。

水平内边距：8–12px。

9.3 操作列
文字按钮间距 8px。

超过 3 个操作收进「更多」。

危险操作放在最后，或收进更多。

必须有禁用态、加载态、键盘焦点态。

9.4 按钮优先级
每屏最多一个主按钮。

主操作靠右。

取消在保存左侧。

删除等危险操作不要与主操作并排突出。

层级	字号/字重	用途
H1	18–20px / 600	页面标题
H2	14–16px / 600	区块标题
H3	13–14px / 600	卡片/表格标题
Body	13px / 400	正文
Table	12–13px / 400	表格内容
Label	12px / 400	标签、辅助文字
要求：

标题与内容间距 8–12px。

辅助文字使用次文本色。

链接使用主色，悬停加深。

11. 表格规范
11.1 结构
表头吸顶。

表头高度 34px。

行高 32/36px。

斑马纹 --erp-table-stripe。

悬停 --erp-table-hover。

选中 --erp-selected-bg。

11.2 对齐与格式
文本左对齐。

数字右对齐。

金额千分位。

日期 YYYY-MM-DD。

空值 -。

状态标签浅色底 + 深色文字。

11.3 列管理
支持列宽调整。

支持显示/隐藏列。

支持排序。

支持筛选。

列多时固定左侧关键列 + 右侧操作列。

横向滚动条始终可见或悬停可见。

11.4 分页与合计
分页靠右或靠下。

合计行固定在底部或表尾。

导出按钮放在表格右上角或筛选区右侧。

12. 表单规范
分组展示，每组有标题。

2–3 列紧凑布局。

标签顶部或右对齐，保持一致。

必填加 *。

校验即时提示。

错误信息在字段下方，红色 12px。

只读字段浅灰背景。

保存、取消固定底部。

主按钮最多一个。

13. 弹窗、抽屉与通知
13.1 弹窗
宽度根据内容决定，最大 720px。

标题 14–16px / 600。

底部按钮右对齐。

使用轻阴影。

Esc 可关闭，Enter 可提交。

13.2 抽屉
宽度 480–720px。

适合编辑、详情、筛选。

顶部标题，底部操作固定。

内容区可滚动。

13.3 通知
成功、警告、错误、信息四类。

2–4 秒自动消失。

可手动关闭。

不要遮挡关键操作。

14. 交互与状态
加载：骨架屏或轻量 loading，避免全屏遮罩。

空状态：说明 + 主操作。

错误：明确原因 + 重试。

通知：2–4 秒自动消失，可手动关闭。

键盘：Tab 顺序合理，Enter/Esc 可提交/关闭。

对比度：正文与背景至少 4.5:1。

焦点：键盘焦点必须可见。

禁用：禁用态清晰，不要只靠降低透明度。

15. 响应式与密度
桌面优先：1366×768 可高效使用。

1280+ 最佳。

最小适配 1024。

侧栏可折叠。

表格横向滚动，固定关键列。

筛选区可折叠。

除表格横向滚动外，页面无横向溢出。

首屏尽量展示更多有效数据。

16. 执行步骤
扫描项目结构、组件库、路由、页面清单，输出改造范围。

建立/统一 design tokens 与全局样式。

改造全局布局：顶栏、侧栏、面包屑、内容容器。

改造通用组件：按钮、输入、表格、表单、弹窗、抽屉、分页、标签、通知。

逐页改造：报表页、维护页、列表页、详情页。

自测：1366×768 与 1280 宽度下检查溢出、对齐、密度、功能回归。

输出：修改文件列表、Token 说明、组件变更、前后对比截图、测试结果。

17. 验收标准
1366×768 首屏信息量明显提升，无大片无效留白。

除表格横向滚动外，页面无横向溢出。

按钮、标题、表格、表单、筛选区风格统一。

无业务功能回归，lint/build/test 通过。

整体观感：专业、紧凑、克制，像成熟 ERP，而不是普通后台模板。

键盘可操作，焦点可见，对比度达标。

主按钮每屏最多一个。

表格表头吸顶、斑马纹、悬停高亮、固定列、分页、导出正常。

表单校验、只读、必填、错误提示正常。
