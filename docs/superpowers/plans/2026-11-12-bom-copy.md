# BOM 复制功能 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 `/base/bom` 页面选中一行后点「复制BOM」，一次性克隆出"父零件物料 + 其BOM"。

**Architecture:** 后端新增 `POST /boms/:id/copy`，单个 `prisma.$transaction` 内先克隆源父零件物料（`code = 源code-copy`）、再以其为 `productId` 建BOM与明细；前端把现有 BOM 编辑弹窗从 `isEdit` 二元标志改造成 `mode: create|edit|copy` 三态，copy 模式下「父零件」下拉换成「新父零件编码」输入框，保存时调用该新接口。

**Tech Stack:** Node 22 / Express 5 / Prisma 5.22（PostgreSQL）后端；Vue 3 + Vite + Element Plus 前端。

**Spec:** `docs/superpowers/specs/2026-11-12-bom-copy-design.md`

## Global Constraints

- **无自动化测试套件**（AGENTS.md）。验证只能用：`cd server && npm run build`（tsc）、`cd client && npm run build`（`vue-tsc -b && vite build`，strict `noUnusedLocals`）、`curl localhost:3000/api/...` + Bearer token。登录：`POST /api/v1/auth/login {"username":"admin","password":"admin123"}`。
- 改了后端必须**重启服务**：`(setsid npx tsx src/index.ts > /tmp/log 2>&1 < /dev/null &)`（在 `server/` 下）。**不要**用 `pkill -f "tsx src/index.ts"`（会匹配到自身 shell）；如需杀进程用 `pkill -f "src/inde[x].ts"` 且单独一条命令。
- 本功能**无 schema 变更** → 不需要 `prisma migrate`、不需要 `prisma generate`。
- Prisma 锁定 `5.22.0`，禁止升级。
- API 统一 envelope `{code,message,data,timestamp}`，成功 `code:200`；前端 axios 拦截器已对非 200 自动 `ElMessage.error(res.message)`，页面里**不要重复弹错误提示**。
- 所有新增路由必须带 `requirePermission("bom:edit")`；`client/src/api/index.ts` 的路径与后端路由镜像。
- UI 文案、注释、提交信息一律中文（项目惯例）。
- 前端 `client/tsconfig` strict：未使用的 import/变量会直接构建失败。
- 材料页 `views/base/material/index.vue` 的行选中模式（`tableRef` + `highlight-current-row` + `@current-change`）是本页要照抄的既有范式。

## Review Focus

以下输入/失败模式没有任何任务的自动化测试覆盖（因为没有测试套件），必须靠任务里列出的 curl 断言或手工验收步骤兜住：

1. **源BOM明细为空** → `assertBomItems` 应报「BOM至少需要一个子件」，且**不留下已建好的空BOM物料**（事务回滚）。归属 Task 1 Step 6 断言 3。
2. **重复的新父零件编码**（预探测没挡住，或用户手输了一个已存在的编码）→ 后端必须 400「物料编码已存在」，不得静默加后缀、不得建出半截数据。归属 Task 1 Step 6 断言2。
3. **源物料 `materialType`/`location` 为 null**（导入的老数据）→ 克隆必须成功，不能被物料新建的必填校验拦下。归属 Task 1 Step 6 断言4。
4. **未选中任何行就点「复制BOM」** → 必须提示「请先点击选择一行」且不打开弹窗。归属 Task 2 Step 8 手工验收 1。
5. **copy 模式下父零件字段未渲染** → `el-form.validate()` 不得因 `productId` 缺失而拦截保存（校验规则必须随 `mode` 切换）。归属 Task 2 Step 7 构建 + Step 8 手工验收 4。
6. **编码预探测请求失败**（调用者没有 `material:view`）→ 静默回退默认 `源code-copy`，由后端 400 兜底，不得让弹窗打不开。归属 Task 2 Step 5 的 try/catch + Step 8 手工验收 5。

### Task 1: 后端原子复制接口 `POST /boms/:id/copy`

**Files:**

**Interfaces:**
- Consumes: `getBom(id)`、`assertBomItems(items)`（均已在 `bom.service.ts` 中存在）、`BomCreateInput["items"]` 类型。
- Produces: `export async function copyBom(id: number, data: BomCopyInput): Promise<any>`，返回新建的 BOM 行（`include: { items: { include: { material: true } } }`），`items` 按 `sortOrder` 升序。Task 2 的 `bomApi.copy` 依赖该路由与该返回形状（前端只用 `res.message` 与返回体的 `code` 字段做提示）。

- [ ] **Step 1: 在 `bom.service.ts` 追加 `BomCopyInput` 接口与 `copyBom`**

```ts
export interface BomCopyInput {
  code?: string;
  version?: string;
  items?: BomCreateInput["items"];
}
```

`copyBom(id, data)` 的行为（签名固定，主体按此写）：

1. `const src = await getBom(id)`；为 null → `throw new Error("BOM不存在")`。
2. `base` = `data.code?.trim()`，为空则取源父零件编码 + 后缀 `-copy`；
   `prisma.material.findUnique({ where: { code: base } })` 命中 → `throw new Error("物料编码已存在")`。
3. `const items = data.items ?? src.items.map(i => ({ materialId: i.materialId, quantity: i.quantity, unit: i.unit, lossRate: i.lossRate ?? 0, sortOrder: i.sortOrder }))`；`await assertBomItems(items)`。
4. `return prisma.$transaction(async (tx) => {...})`，事务内按序：
   - `tx.material.create`：`code: base`，`status: 1`，**其余字段从 `src.product` 解构照抄**——
     `name, specification, description, packageType, brand, category, unit, safetyStock, minStock, maxStock, leadTime, manufactureLeadTime, orderCycleDays, materialType, minOrderQty, cost, price, location, supplierId, batchManaged, remark, desc1, desc2, desc3, desc4, processRouteId, bomcode`。
     **直接 `tx.material.create`，不得改调 `createMaterial`**（后者强制 `materialType`/`location` 非空，会挡住老数据）。
   - `tx.bom.create`：`code: newMat.code`、`name: newMat.code`、`productId: newMat.id`、
     `version: data.version || src.version || "1.0"`、`status: "active"`。
   - 逐条 `tx.bomItem.create`（`sortOrder` 用 `i.sortOrder ?? index + 1`，`lossRate` 用 `i.lossRate ?? 0`），随后 `tx.bom.findUnique({ where: { id: bom.id }, include: { items: { include: { material: true }, orderBy: { sortOrder: "asc" } } } })` 返回。

新增预探测函数（**必须整段包在 try/catch 内**，失败静默回退默认值——Review Focus 6）：
```ts
async function resolveCopyCode(base: string): Promise<string> {
  const first = `${base}-copy`
  try {
    const res: any = await materialApi.list({ keyword: base, pageSize: 100 })
    const taken = new Set((res.data.items as any[]).map((m: any) => m.code))
    if (!taken.has(first)) return first
    let n = 2
    while (taken.has(`${first}${n}`)) n++
    return `${first}${n}`
  } catch {
    return first
  }
}
```
（后缀口径固定：`源code-copy` → `源code-copy2` → `源code-copy3`，即 `${first}${n}`，与 spec 一致。）
