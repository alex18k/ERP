# 进销存管理系统 报价说明

## 一、产品概述

本系统基于现有 ERP 平台的销售、采购、库存与基础数据能力，提供一套覆盖「进、销、存」全流程的进销存管理解决方案。涵盖物料、客户、供应商、仓库等基础档案，以及销售订单、采购订单、出入库、库存查询、批号管理、单据打印与经营报表等完整业务闭环。

## 二、功能模块清单

### 1. 基础数据
- 物料主文件（编码、规格、类别、提前期、安全库存、成本、批号管理开关）
- 物料类别管理
- 客户管理
- 供应商管理
- 仓库 / 库位管理
- 事务类型管理
- 基础数据 CSV 批量导入

### 2. 销售管理
- 销售订单：创建 → 确认 → 发运 → 完成/取消
- 销售订单明细（数量、单价、交货期）
- 订单跟踪（按状态查询订单执行进度）
- 销售发货（出库、库存扣减、流水记录）
- 销售订单打印

### 3. 采购管理
- 采购订单：创建 → 确认（审核）→ 到货 → 入库
- 采购订单明细（数量、单价、交期、采购员、供应商）
- 到货登记
- 采购入库（生成库存与流水）
- 采购订单打印

### 4. 库存管理
- 库存查询（按物料/仓库/批号多维查询，低库存预警标记）
- 批号管理（批号级库存、批号查询）
- 库存流水（收/发/调记录，事务类型追溯）
- 收料入库 / 发料出库 / 销售出库 / 采购入库
- 库存 CSV 导出

### 5. 报表与看板
- 库存看板（库存分布、安全库存预警）
- 订单跟踪看板
- 经营报表与统计
- 移动端查询报表

### 6. 系统管理
- 用户管理与登录认证
- 角色与权限（菜单/接口级权限控制）
- 操作日志
